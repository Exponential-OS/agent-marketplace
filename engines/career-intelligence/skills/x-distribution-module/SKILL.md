# X (Twitter) Distribution Module

## Purpose

This skill acts as a Spoke to drive real-time engagement back to the Hub (The Juice) or the Honey Pot (Substack).

## Capabilities

### 1. Thread Mechanics & Algorithmic Rules
- **Link Penalties:** External links suppress reach by ~50%. Put the core value in the main tweet, and place the link to the Substack/LinkedIn Hub in **Reply 2** (buried to avoid penalty).
- **Images:** Photos boost impressions. Use a single square (1080x1080) image on the first tweet.
- **Tagging:** Tag relevant accounts strategically in the body to boost signal, but do not spam.
- **Thread Structure:** Main tweet hooks → Reply 1 delivers value → Reply 2 has the link.

### 2. The Vortex
- Cross-link the new thread to the pinned thread on the profile to compound the flywheel.
- Engage in reply-to-reply loops to train the algorithm.

### 3. Record Execution
Update the campaign tracker with the thread URL.
